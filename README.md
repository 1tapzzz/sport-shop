# SPORTZONE — интернет-магазин спортивных товаров

SPORTZONE — учебный интернет-магазин спортивной одежды, обуви и аксессуаров. Проект создан с использованием React на frontend и Python/Django на backend.

## Возможности проекта

- Главная страница со слайдером и категориями товаров.
- Каталог товаров с поиском и фильтрацией.
- Карточки товаров с изображениями, описанием и ценой.
- Корзина с добавлением и удалением товаров.
- Изменение количества товаров в корзине.
- Автоматический расчёт стоимости корзины.
- База данных SQLite для хранения товаров и корзины.
- Административная панель Django для управления товарами.
- Адаптивный дизайн для мобильных устройств.

### Функции в разработке

- Регистрация пользователей.
- Авторизация и выход из аккаунта.
- Профиль пользователя.
- Оформление и хранение заказов.

## Установка проекта

Склонируйте репозиторий:

```bash
git clone https://github.com/1tapzzz/sport-shop.git
cd sport-shop
```

## Настройка Backend

Все команды ниже предназначены для Windows PowerShell.

### 1. Создание виртуального окружения

Выполняйте команды из корневой папки `sport-shop`:

```powershell
py -3.14 -m venv .venv
```

### 2. Активация окружения

```powershell
.\.venv\Scripts\Activate.ps1
```

После активации в начале строки терминала появится `(.venv)`.

### 3. Установка Python-библиотек

```powershell
python -m pip install -r requirements.txt
```

### 4. Создание таблиц базы данных

```powershell
cd backend
python manage.py migrate
```

### 5. Создание администратора

Выполните эту команду один раз для нового локального окружения:

```powershell
python manage.py createsuperuser
```

Следуйте инструкциям в терминале и придумайте пароль.

### 6. Запуск Django

```powershell
python manage.py runserver
```

Backend будет доступен по адресу:

http://127.0.0.1:8000/

## Настройка Frontend

Откройте **второй терминал** VS Code. Перейдите в корневую папку проекта:

```powershell
cd "путь-к-папке-с-проектом\sport-shop"
```

Установите зависимости React:

```powershell
npm install
```

Запустите frontend:

```powershell
npm run dev
```

Vite выведет адрес сайта, обычно:

http://localhost:5173/

Если порт занят, Vite может выбрать другой, например 5174. Открывайте адрес, который показан в терминале.

**Важно:** терминалы с Django и React должны оставаться открытыми во время работы сайта.

## Административная панель

Откройте:

http://127.0.0.1:8000/admin/

Войдите с учётными данными администратора.

В админке можно добавлять, редактировать и удалять товары.

Для каждого товара указываются:

- Название.
- Описание.
- Цена.
- Ссылка на изображение.
- Категория.
- Статус активности.

Чтобы товар отображался в каталоге, установите статус «Активен».

Для корректной работы текущих фильтров используйте категории:

- Обувь
- Одежда
- Аксессуары

Ссылка на изображение должна вести непосредственно к изображению, доступному браузеру.

## API

Основные адреса Django API:

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/products/` | Получение списка товаров |
| GET | `/api/cart/` | Получение корзины |
| POST | `/api/cart/items/` | Добавление товара |
| PATCH | `/api/cart/items/<id>/` | Изменение количества |
| DELETE | `/api/cart/items/<id>/` | Удаление товара |

Пример запроса на добавление товара:

```json
{
  "product_id": 1,
  "quantity": 2
}
```

Корзина привязана к сессии посетителя. Браузер должен передавать cookies при запросах к API.

## База данных

В разработке используется SQLite. При первом запуске создайте таблицы командой:

```powershell
python manage.py migrate
```

Файл базы данных `backend/db.sqlite3` хранится локально и не должен добавляться в Git.

После нового клонирования репозитория база будет создана заново. Добавьте тестовые товары через Django Admin.

## Решение возможных проблем

### React не запускается

Убедитесь, что вы находитесь в корневой папке проекта и зависимости установлены:

```powershell
npm install
npm run dev
```

### Django не запускается

Убедитесь, что виртуальное окружение активировано и текущая папка — `backend`:

```powershell
python manage.py runserver
```

### React не подключается к Django

Проверьте, что оба сервера запущены.

В `backend/config/settings.py` настройка `CORS_ALLOWED_ORIGINS` должна включать адрес, с которого открыт React, например `http://localhost:5173` или `http://localhost:5174`.

После изменения настроек перезапустите Django.

### В каталоге нет товаров

Откройте Django Admin и добавьте товары. Проверьте, что они активны и сохранены.
